# fitflow-redesign

FitFlow Redesign
IT3060 Human Computer Interaction
This repository contains the technology comparison, technology decision matrix, high-level architecture, and supporting documentation for the FitFlow redesign project.

Project Overview
FitFlow is a fitness application redesign focused on improving usability, personalization, nutrition tracking, progress monitoring, and community features.

The technology selection was carried out based on the requirements identified during the previous HCI usability evaluation.
